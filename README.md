## How this repo works
- **One canonical `.md` per concept** (e.g. `02-Web-Security/xxe.md`) — everything about that topic in one file.
- Deep theory + code + CVEs + exploitation live in the **domain folders**.
- Quick-recall interview answers live in **`99-Interview/`**.
- Real work (sanitised) lives in **`16-Real-World-Projects/`** — gold for senior interviews.
- Every topic follows a consistent template: see `TEMPLATE-vuln.md` / `TEMPLATE-concept.md`.

## Rule
GitHub = source of truth. The dashboard only holds status/links — never duplicate content.
